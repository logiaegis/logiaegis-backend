# LogiAegis Backend (NestJS)

The official backend API for LogiAegis.

## 🚀 Overview
LogiAegis is an evidence-first decision layer for global trade. This backend handles authentication, email sending, and database storage.

## 🛠️ Tech Stack
- **Framework:** NestJS
- **Database:** PostgreSQL (via Neon)
- **ORM:** Prisma
- **Email:** Resend API

## 📦 Installation
1. Clone the repo
2. Run `npm install`
3. Create a `.env` file (copy `.env.example`)
4. Run `npm run start:dev`
